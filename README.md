## ステップ1：見せ方（A「いま」→ B 今日の時間の川 → C 締切の地平線）

- `index.html`：iPhoneのホーム画面に置くWebアプリ。横スワイプで3枚
- `gas/Code.gs`：Googleカレンダーの予定を合言葉つきで渡すApps Script

予定の中身はこのリポジトリに置かない。アプリはApps Scriptから読み、端末の中にだけ保存する。

### つなぎ方

1. Apps Scriptに `gas/Code.gs` を貼り、`setup()` を1回実行して合言葉をログで確かめる
2. デプロイ → 新しいデプロイ → ウェブアプリ（実行：自分／アクセス：全員）でURLを出す
3. iPhoneで `https://zhongtianhu902-cloud.github.io/Levi/#u=<URL>&k=<合言葉>` を開く（一度開けば端末に保存される）
4. （任意）共有 → ホーム画面に追加。ホーム画面版はSafariと保存場所が別なので、⚙︎の設定を入れ直す
5. 待機画面の右ボタン：ショートカットアプリで「URLを開く」（https://zhongtianhu902-cloud.github.io/Levi/）のショートカット「リヴァイ」を作り、待機画面を長押し → カスタマイズ → ロック画面 → 右下の懐中電灯を外して「ショートカット」→「リヴァイ」

## 予定を入れる・直す

- 右下の「＋」に一言（例：`10/27までに初任研指導報告書修正`、`明日18時 みゆ迎え`）。何行でも可
- 日付・時刻・分類（家族/仕事/組合）がそろえばそのまま登録。足りないところだけ色つきで聞く
- 締切ものは、リヴァイが逆算して「やる日」を置く（下の「締切の逆算」）
- 表示中の予定（A の次の約束、B の予定、C の締切、暦の一覧）を長押しすると、直す・消すができる

## 月の暦（サブ画面）

- 各画面の見出しの 🗓 で開く（メインはA→B→Cのまま）。締切の地平線＋今月から6か月の暦（〆印、家族緑/仕事青/組合赤の点）。日をタップでその日の一覧、種類でしぼり込み

- `gas/Code.gs` を変えたら、Apps Scriptに貼り直して「デプロイを管理 → 新バージョン」で更新する（URLはそのまま）。くわしくは下の「Apps Scriptへの反映」

### カテゴリの見分け方

## ステップ2：締切の逆算と天気

### 締切の逆算（Apps Script）

- アプリが予定を取りに来たとき、3週間以内の締切（タイトルに「締切・期限・〆」）で、まだ作業が置かれていないものに `▶ 〜` の作業日を置く
- 回数：締切まで8日以上なら3回（とりかかる→半分→仕上げ）、3〜7日なら2回、1〜2日なら1回。仕上げは締切の2日前（近ければ前日）
- 時間帯：仕事・組合は平日15:30〜17:30の空き（土日・祝日・休みの日は置かない）、家族は平日20:00〜21:00か休日9:00〜11:00。1回30分（締切の説明に「作業60分」などと書けばその長さ）
- 置いた作業の説明に「ここまで：〜（1/3）」「締切M/Dの逆算」を書く。アプリは A「いま」と C に「今日はここまで」を出す
- 置いたら締切の説明に「（逆算済み）」を付ける。▶ を消しても置き直さない。逆算してほしくない締切は説明に「（逆算しない）」
- すでに作業が置かれている締切（説明に「作業日・逆算・計画」、または作業の説明に「締切M/D」）は、印だけ付けて触らない

### 天気（アプリ）

- 大分市の天気を Open-Meteo（登録不要）から30分ごとに取り、予定に結びつけて出す
- A「いま」：お迎えや外の予定に雨がかかるとき、朝の冷え込み・寒暖差があるときだけ「天気」に一言（夕方からは明日の分も）
- B：今日の天気を1行、雨にかかる予定に ☔
- 朝の声かけ（ステップ4）では `weatherNotes()` をそのまま使う

## ステップ3：声かけ（通知）

- Apps Scriptが5分ごとに見回り（`tick`）、朝・昼・夕の定時と、予定の直前に通知を送る。押すと A「いま」が開く
  - 朝（6:30）：最初の約束、家族の予定、今日のやる（ここまで）、近い締切、予定にかかわる天気
  - 昼（12:30）：午後のやる、次の約束、家族の予定に向けた切り上げ時刻
  - 夕（16:30）：お迎えなど家族の予定と切り上げ時刻、明日の最初の約束、近い締切
  - 直前：予定の10分前（家族は15分前）。「18:10 スイミング迎え まであと15分／18:05までに切り上げ」。▶ の作業は「とりあえずここまで」。授業（○限）の前は鳴らさない
  - 時刻と何分前は、アプリの⚙︎で変えられる（Apps Scriptに保存、全端末共通）
- しくみ：Web Push（VAPID）。Apps Scriptは「中身なしの合図」だけを送り、合図を受けた `sw.js` が `?a=inbox` で文面を取って出す（暗号化が要らないため）。署名（ES256）はCode.gsの中で計算する
- 同じ声かけは1日1回。Apps Scriptが30分以上止まっていたら、その間の分はまとめて送らない

### つなぎ方（1回だけ）

1. `gas/Code.gs` を貼り直して保存 →「デプロイを管理 → 鉛筆 → 新バージョン」（下の「Apps Scriptへの反映」の1〜4）
2. エディタの上で関数 `setupPush` を選んで「実行」。許可を聞かれたら「許可」（外部への接続とトリガーの許可）
3. iPhone（とiPad）の**ホーム画面のリヴァイ**で ⚙︎ →「通知をオンにする」→ 通知を「許可」。Safariのタブからでは通知は使えない
4. 「ためしに送る」で、次の予定の直前の声かけが届くか確かめる

## Apps Scriptへの反映（`gas/Code.gs` を変えたとき・毎回）

### 1. 反映先をまちがえない

- 反映先は、**zhongtianhu902 アカウント**の「**無題のプロジェクト**」のうち、**2026年10月20日に作ったほう**
- 同じ名前の「無題のプロジェクト」（9月21日に作ったほう）もあるが、こちらはリヴァイではない。触らない
- 見分け方：Apps Scriptのホーム（script.google.com）の一覧で「作成日」を見る

### 2. コードを丸ごと置き換える

1. エディタで「コード.gs」を開き、中身をすべて選んで消す（⌘A → delete）
2. このリポジトリの `gas/Code.gs` の中身をすべてコピーして貼る。一部だけ書き直すことはしない
3. 保存（⌘S）

### 3. SHA-256 で同じものか確かめる

貼りまちがい・貼り残しがないかを、指紋（SHA-256）で確かめる。Macのターミナルで：

```sh
# リポジトリ側
shasum -a 256 gas/Code.gs

# エディタ側（エディタで ⌘A → ⌘C してから）
pbpaste | shasum -a 256
```

- 2つの英数字が同じなら OK
- 違うときは、まず最後の改行の有無を疑う（`pbpaste | wc -c` と `wc -c < gas/Code.gs` で文字数を比べ、1だけ違うなら末尾の改行）。それ以外の違いなら、もう一度2からやり直す

### 4. 既存のデプロイを新バージョンにする（URLを変えない）

1. 右上の「デプロイ」→「デプロイを管理」
2. いまのウェブアプリを選んで鉛筆（編集）
3. 「バージョン」を「新バージョン」にして「デプロイ」
4. URLが前と同じであることを確かめる

「新しいデプロイ」は使わない。URLが変わり、iPhoneのリヴァイ（`#u=<URL>`）と通知がつながらなくなる。

### 5. 新しい許可を聞かれたとき

- 外部への接続やトリガーなど、新しい権限が要るコードに変えると、実行時に「承認が必要です」と出る
- 許可は、**ふだん使いの Chrome** で、**zhongtianhu902 アカウント**にログインした状態で行う
- Claudeのアプリの中のブラウザ（アプリ内ブラウザ）では許可しない。ログインが別になっていて、うまく通らないことがある
- 「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」

### 6. 許可を変えたあとは `setupPush` を実行する

- 許可を出し直したら、エディタの上で関数 `setupPush` を選んで「実行」
- 5分ごとの見回り（`tick`）のトリガーが置き直され、通知が止まらない
- 終わったら、アプリの⚙︎「ためしに送る」で通知が届くか確かめる
